Start here

Run your first mission.

Install the SDK, create an agent with a scoped tool set, and execute a mission inside a persistent workspace—with governance applied at execution time.

01 · INSTALL

Add the SDK

Install for Python or TypeScript and set your API key as an environment variable.

02 · DEFINE

Create an agent

Give it a role, a model, an allowed tool set, a budget, and an approval policy.

03 · EXECUTE

Run a mission

Start a mission in a workspace. Inspect every tool call, file, and decision as it runs.

04 · GOVERN

Gate the consequential step

Require human approval before any external write, deploy, or payment.

terminal · python
# install
pip install aadml

# authenticate
export AADML_API_KEY="sk-..."

from aadml import Client

client = Client()

agent = client.agents.create(
    name="benefits-caseworker",
    model="reasoning-pro",
    tools=["browser", "postgres", "documents"],
    budget_usd=5.00,
    approval="ask",   # human gate on writes
)

run = client.missions.run(
    agent=agent.id,
    goal="Review case 21874 and prepare a decision",
    workspace="case-21874",
)

for event in run.stream():
    print(event.type, event.summary)
